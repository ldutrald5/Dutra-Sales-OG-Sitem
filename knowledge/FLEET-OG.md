# Fleet Context for DUTRA OS

Purpose: provide the minimum fleet vocabulary/context needed to ask correct questions and route technical work. Product application remains governed by validated OG evidence.

## Configurations represented in the current product

The current vehicle catalog/code includes configurations such as:

- 3/4;
- Toco 4x2;
- Truck 6x2;
- Bi-Truck 8x2;
- cavalo 4x2 + carreta;
- cavalo 6x2 + carreta;
- trucado + reboque / Romeu e Julieta;
- Bitrem 7 eixos;
- Rodotrem 9 eixos.

Treat these labels as application inputs, not as sufficient evidence for a support code.

## Position vocabulary used by the system

- dianteira / direcional;
- tração;
- truck;
- carreta/reboque;
- eixo/quantidade de eixos.

## Questions before technical application

When relevant, establish:

1. exact composition of the vehicle/conjunto;
2. brand/model/year;
3. axle arrangement and driven axles;
4. suspension type;
5. reduction hub;
6. wheel/rim detail if the rule depends on it;
7. whether the front axle will be equipped;
8. operating pressure required by the customer's actual setup.

Unknown answers stay unknown.

## Fleet-manager framing

Commercial preparation should translate the discussion into the customer's real operation:

- vehicles/conjuntos involved;
- tires protected;
- current maintenance/pressure process;
- wear/cost problem stated by the customer;
- rollout or test scope;
- investment per vehicle/conjunto when calculated;
- next validation step.

Never fabricate fleet size, current tire cost, savings or ROI.
