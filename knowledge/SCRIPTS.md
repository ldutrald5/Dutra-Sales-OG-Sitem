# Scripts comerciais

## Princípio

Scripts são guias adaptáveis. Devem indicar objetivo, perguntas e próximo passo, sem inventar fatos sobre a conta ou o produto.

## Formato

```text
Nome e versão:
Objetivo:
Estágio/segmento:
Pré-requisitos:
Abertura:
Perguntas:
Transições:
Objeções relacionadas:
CTA/próximo passo:
Campos para registrar:
Fonte/aprovação:
```
