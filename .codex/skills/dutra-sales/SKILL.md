# DUTRA Sales

## Load
- current CRM/account facts first;
- `knowledge/VENDAS-OG.md`;
- `knowledge/SCRIPTS.md`;
- `knowledge/OBJECOES.md`;
- `docs/playbooks/SALES_PLAYBOOKS.md`;
- Sales Execution contract when workflow/state is involved.

## Procedure
1. Identify relationship + pipeline stage.
2. Separate confirmed facts, hypotheses and suggested moves.
3. Define one objective for the interaction.
4. Use stage-specific questions and language.
5. Avoid unsupported product/ROI claims.
6. End with a concrete next action and capture the confirmed result.

## Guardrails
- Existing customer is not a cold lead.
- Gatekeeper objective is access/identity, not a full technical pitch.
- Follow-up resumes the recorded commitment instead of restarting.
- Post-sale resolves experience/issues before expansion/referral.
- Proposal/discount/tax/stock/delivery facts require current evidence/authority.
- No external action is claimed from UI navigation alone.

## Output
Context → objective → approach → questions → objections/guardrails → next step → fields to record.

## V3 domain guidance retained for later convergence

Current Environment Guardian, canonical data and tested baseline rules above take precedence.

# DUTRA Sales

## Quando usar

Conversas, Call AI, playbooks, próximas ações, follow-up, reunião, proposta e expansão.

## Carregar

- `docs/playbooks/SALES_PLAYBOOKS.md`
- `knowledge/SCRIPTS.md`
- `knowledge/OBJECOES.md`
- contexto real da conta via CRM.

Se houver proposta técnica: adicionar `dutra-og-tech` e `dutra-quote-engine`.

## Regras

- adaptar à relação real da conta;
- cliente existente não é cold;
- gatekeeper: cooperação/descoberta, não pitch técnico longo;
- decisor: diagnóstico antes de explicação extensa;
- oportunidade qualificada muda o objetivo para próxima etapa/reunião;
- follow-up continua do ponto combinado;
- proposta aberta não significa enviada/lida/aceita;
- pós-venda prioriza experiência/expansão antes de indicação;
- não inventar prova, ROI, economia ou aplicação.

## Saída durante ligação

Curta: objetivo, abertura, 3–5 perguntas, gancho, objeções, CTA.

## Persistência

Sugestão da IA é revisável. Registrar somente fatos confirmados, resultado e próxima ação.
