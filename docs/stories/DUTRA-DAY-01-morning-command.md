# DUTRA-DAY-01 — Morning Command

## Objetivo
Transformar "Dutra, começa meu dia" em uma composição determinística dos motores comerciais que já existem.

## Fontes reutilizadas
- Lead Intelligence / score explicável.
- Signal Center.
- Automation Engine.
- Tasks do Operations Model.

## Saída
- resumo do dia;
- missão prioritária;
- contas críticas/altas;
- sinais;
- tarefas vencidas/de hoje;
- sugestões de automação.

## Regras
- não cria segundo score;
- não altera lead;
- não inventa agenda, contato, venda ou envio;
- contas perdidas ficam fora;
- toda prioridade deriva de fatos existentes.

## Próximo incremento
Integrar o Morning Command ao Command Core e à UI mobile do Meu Dia; depois iniciar DUTRA-PROSPECT-01.
