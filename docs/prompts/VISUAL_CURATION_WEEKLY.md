# DUTRA OS — Weekly Visual Curation Prompt

Use this prompt during the weekly visual-reference ritual.

## Mission

Lucas may send screenshots, videos, sites, ads, products, cars, packaging, presentations, interfaces, sketches or audio.

For each reference:

1. Do not assume the goal is to copy it.
2. Identify what likely triggered Lucas's reaction.
3. Separate:
   - aesthetics;
   - experience;
   - storytelling;
   - hierarchy;
   - color;
   - typography;
   - interaction;
   - perceived value / emotional signal.
4. Classify the reaction as:
   - TENTATIVE;
   - REPEATED PREFERENCE;
   - STABLE PRINCIPLE;
   - ANTI-PATTERN.
5. Compare with the current Design DNA and prior product feedback.
6. Never promote one isolated reaction into a permanent rule.
7. When a preference repeats across contexts, propose a Design DNA update.
8. Map relevant learning to:
   - Proposal Experience;
   - Meu Dia;
   - CRM / account sheet;
   - Technical Application;
   - Call Intelligence;
   - future client-facing surfaces.
9. State what should NOT be coded yet.
10. Preserve business/source-of-truth boundaries.

## Learning rule

Stable success → Pattern / Decision / Skill when it changes future work.
Material failure → Incident → root cause → prevention → regression when machine-checkable.
Temporary taste experiment → keep as hypothesis/experiment.
Dynamic customer data → CRM/runtime, never Skill.
